# Philippine Fish Species Classifier

A CPU-friendly AI prototype that classifies Philippine fish species using
MobileNetV2 transfer learning. Includes automatic dataset download, model
training, TFLite/TF.js export, and a browser-based test page.

**Hardware target:** AMD A8-7680 · 12 GB RAM · AMD Radeon R7 (integrated)

## Quick Start

### Step 0 — Install dependencies
```bash
pip install -r requirements.txt
```

### Step 1 — Download sample images automatically
```bash
python download_dataset.py
```
Downloads ~20 training + 5 validation images per species from Bing.

### Step 2 — Train the model
```bash
python train_fish_classifier.py
```
- Phase 1: trains classifier head (~10-15 min on CPU)
- Phase 2: fine-tunes last 30 MobileNetV2 layers (~10-15 min)
- Saves `fish_classifier.h5` and `training_curves.png`

### Step 3 — Export for web / mobile
```bash
python convert_model.py
```
Produces:
- `fish_classifier.tflite` — for Android / iOS
- `web/model/model.json` + `*.bin` — for the browser

### Step 4 — Test in browser
Open `web/index.html` directly in Chrome or Edge.
Drag a fish photo onto the page to classify it — **no internet or server needed.**

### Step 5 — CLI prediction (optional)
```bash
python predict_fish.py path/to/photo.jpg
```

## AMD GPU Setup (optional — gives ~2-5× speedup)

```bash
pip install tensorflow-directml
```
Then in `train_fish_classifier.py` set:
```python
USE_DIRECTML = True
```
This enables the AMD Radeon R7 integrated GPU via Microsoft DirectML.

## Adding More Species

1. Create `dataset/train/<NewSpecies>/` and add ≥10 images.
2. Create `dataset/validation/<NewSpecies>/` and add 3-5 different images.
3. Re-run Steps 2–4.

Zero code changes needed — the scripts detect subfolders automatically.

---

## Key Configuration (train_fish_classifier.py)

| Variable         | Default | Description                                   |
|------------------|---------|-----------------------------------------------|
| `BATCH_SIZE`     | 8       | Lower = less RAM                              |
| `INITIAL_EPOCHS` | 20      | Phase 1 epochs (early stopping applies)       |
| `FINE_TUNE_EPOCHS`| 15     | Phase 2 epochs                               |
| `FINE_TUNE_AT`   | 30      | MobileNetV2 layers to unfreeze (0 = skip P2) |
| `USE_DIRECTML`   | False   | Set True for AMD/Intel iGPU on Windows        |

## Quick Start

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Add your images
Put your fish photos into the correct subfolders:
- `dataset/train/Bangus/`      — 10-20 Bangus images
- `dataset/train/Tilapia/`     — 10-20 Tilapia images
- `dataset/train/Galunggong/`  — 10-20 Galunggong images (optional)
- Same for `dataset/validation/` using DIFFERENT images (3-5 each)

### 3. Train the model
```bash
python train_fish_classifier.py
```
This will:
- Load your images and augment them automatically
- Download MobileNet pretrained weights (~17 MB, once)
- Train Phase 1: classifier head (~5-10 min on CPU)
- Train Phase 2: fine-tune last layers (~5-10 min on CPU)
- Save `fish_classifier.h5`
- Save `training_curves.png`

### 4. Predict a species
```bash
python predict_fish.py path/to/your/fish_photo.jpg
```
