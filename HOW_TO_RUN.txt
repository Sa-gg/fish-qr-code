SYSTEM OVERVIEW
===============
Your setup has 4 Python scripts and 1 web page that work in sequence:

  [1] download_dataset.py     Downloads fish images automatically
       ↓
  [2] train_fish_classifier.py Trains the AI model
       ↓
  [3] convert_model.py        Exports model for browser/mobile
       ↓
  [4] web/index.html          Browser test page

═══════════════════════════════════════════════════════════════
STEP 1 — DOWNLOAD FISH IMAGES  (~2-3 minutes)
═══════════════════════════════════════════════════════════════

  cd "C:\Users\Name\Desktop\FINE TUNED"
  C:/Users/Name/AppData/Local/Programs/Python/Python310/python.exe download_dataset.py

What it does:
  - Searches Bing for "Bangus milkfish Philippines", "Tilapia fish Philippines",
    "Galunggong round scad Philippines" etc.
  - Downloads ~20 images per species into dataset/train/
  - Automatically splits 5 images per species into dataset/validation/
  - Skips broken/tiny files automatically

Expected output:
  Train:
    Bangus          ~19 images
    Galunggong      ~19 images
    Tilapia         ~19 images
  Validation:
    Bangus          ~5 images
    (etc.)

To use YOUR OWN photos instead:
  Just copy JPG/PNG files into the correct subfolder manually.
  Example: Copy your Bangus photos to  dataset/train/Bangus/


═══════════════════════════════════════════════════════════════
STEP 2 — TRAIN THE AI MODEL  (~30-60 min on CPU)
═══════════════════════════════════════════════════════════════

  C:/Users/Name/AppData/Local/Programs/Python/Python310/python.exe train_fish_classifier.py

What happens:
  PHASE 1 (fast ~10 min):
    - Loads MobileNetV2 with ImageNet pretrained weights
    - Freezes all 154 MobileNetV2 layers (no updates)
    - Trains only the new classifier head (256-neuron + output layer)
    - Saves checkpoints/phase1_best.h5 after each improvement
    - Stops automatically if accuracy stops improving (EarlyStopping)

  PHASE 2 — Fine-tuning (slower ~20-40 min):
    - Unfreezes the last 30 MobileNetV2 layers
    - Retrains with very small learning rate (5e-6)
    - BatchNorm layers remain frozen for stability
    - Saves checkpoints/phase2_best.h5

  Outputs:
    fish_classifier.h5       — the trained model
    class_indices.json       — species label mapping
    training_curves.png      — accuracy/loss chart

What to expect:
  With only ~57 images total, accuracy is typically 40-70%.
  This is a PROTOTYPE — accuracy improves significantly with more images.
  Random chance = 33% (3 species). Anything above that means it's learning.


═══════════════════════════════════════════════════════════════
STEP 3 — CONVERT MODEL FOR BROWSER  (~1-2 minutes)
═══════════════════════════════════════════════════════════════

  C:/Users/Name/AppData/Local/Programs/Python/Python310/python.exe convert_model.py

What it does:
  - Loads fish_classifier.h5
  - Converts to TFLite (for Android/iOS) → fish_classifier.tflite
  - Converts to TensorFlow.js format (for browser) → web/model/
  - Copies class_indices.json to web/ folder
  - Runs a quick smoke test to verify TFLite model works

Output files:
  fish_classifier.tflite        — mobile app format
  web/model/model.json          — TF.js model architecture
  web/model/group1-shard1of1.bin — TF.js model weights
  web/class_indices.json        — species labels for web app

═══════════════════════════════════════════════════════════════
HOW TO IMPROVE ACCURACY
═══════════════════════════════════════════════════════════════

Current: ~57 training images     → expect 40-70% accuracy
Better:  ~200 training images    → expect 70-85% accuracy
Good:    ~500+ training images   → expect 85-95% accuracy

Tips:
  - Use photos with clear, well-lit fish on a clean background
  - Vary angles: top-down, side view, at-market
  - Avoid photos where the fish takes up less than 30% of the frame
  - Remove any misclassified auto-downloaded images manually


═══════════════════════════════════════════════════════════════
COMMON ERRORS & FIXES
═══════════════════════════════════════════════════════════════

Problem: "python is not recognized"
Fix:     Use the full path:
         C:/Users/Name/AppData/Local/Programs/Python/Python310/python.exe

Problem: "Module not found: tensorflow"
Fix:     C:/Users/Name/AppData/Local/Programs/Python/Python310/python.exe -m pip install tensorflow

Problem: "Cannot load model" in web app
Fix:     Run convert_model.py first

Problem: npm error / node_modules error
Fix:     Those are NOT needed. Ignore npm completely.
         The web app uses TF.js from CDN automatically.

Problem: Low accuracy (stuck at 33%)
Fix:     Download more images, or add your own photos.
         33% = random guessing = the model hasn't learned much yet.

Problem: Training is very slow
Fix:     This is normal on CPU. AMD A8-7680 = ~5-10 min per epoch.
         You can set FINE_TUNE_AT = 0 at the top of train_fish_classifier.py
         to skip Phase 2 and save ~30 minutes (at cost of some accuracy).
