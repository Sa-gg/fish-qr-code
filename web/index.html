ℹ️ How to use this page
  1. Run python train_fish_classifier.py to train the model.
  2. Run python convert_model.py to export the model to web/model/.
  3. Open this page (web/index.html) directly in Chrome/Edge — no server needed.
  4. Upload or drag a fish photo to classify it.

Adding species: add a folder in dataset/train/, retrain, reconvert, refresh.

Offline use: the model files inside web/model/ are loaded from your local disk — no internet connection required after the first set-up.
